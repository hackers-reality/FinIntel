## 🛡️ Core Capabilities

### 1. Autonomous "Titan Sentinel"
A background kernel that scans the world 24/7. It tracks:
- **Indian Market Titans:** Vijay Kedia, Ashish Kacholia, Mukul Agrawal, and the Rare Enterprises (Jhunjhunwala) legacy.
- **Regulatory Shifts:** Live monitoring of SEBI circulars and RBI policy changes.
- **Global Events:** Real-time analysis of market-moving announcements (e.g., Elon Musk, Crypto trends).
- **Auto-Discovery:** Automatically triggers "Mega Research" cycles when high-impact events are detected.

### 2. Strategic Research Engine (MEGA)
Deep-dive synthesis across three credibility tiers:
- **Tier 1:** Regulatory (NSE/BSE/SEBI)
- **Tier 2:** Professional (Financial News/Blogs)
- **Tier 3:** Sentiment (Twitter/X, Reddit, Community)
- **Outputs:** Investment Rationale, Long vs. Short Term Strategy, Asset Allocation, and Moat Analysis.

### 3. Semantic Kernel Memory
A conversational AI advisor that learns your interests over time.
- **Context Awareness:** Remembers your risk tolerance and preferred assets.
- **Distillation Engine:** Automatically prunes raw chat logs into semantic summaries to maintain a lean 10MB memory footprint while preserving intelligence.

### 4. High-Fidelity Dashboard
- **Glassmorphism UI:** Mobile-first, responsive design for desktop and Android browsers.
- **Advanced Charting:** Candlestick charts with technical overlays (MA, RSI, Bollinger).
- **Sovereign Vault:** Pin high-conviction opportunities to your private vault.

## ⚙️ Setup & Installation

### Prerequisite: API Keys
FinIntel Pro requires at least one LLM API key. Supported providers:
- **OpenAI (GPT-4o)**
- **Anthropic (Claude 3.5)**
- **NVIDIA NIM**
- **Groq (Llama 3.1)**

### 🚀 Launching the Engine
1. **Clone the repository.**
2. **Run the Installer** (Administrator Mode recommended for PATH setup):
   ```powershell
   .\install.ps1
   ```
3. **Start the Command Center:**
   Simply type the global command:
   ```bash
   finintel
   ```

## 🔐 Security & Sovereignty
- **AES-256 Encryption:** All LLM API keys are encrypted at rest using local machine-specific keys.
- **Self-Hosted:** No data leaves your machine except for direct LLM API calls.
- **Local Persistence:** All history, memory, and saved picks are stored in a local SQLite database.

## 📂 Project Structure
- `/backend`: FastAPI kernel, Sentinel monitoring, and LLM orchestration.
- `/src`: React + Vite + Tailwind glassmorphism interface.
- `run.py`: The Sovereign Orchestrator.
- `DATA_SOURCES.md`: Detailed rationale on real-time data strategy.
