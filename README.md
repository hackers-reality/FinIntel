## ⚡ Zerodha Tactical Integration

### Option A: Zero-Touch Auth (Recommended)
1. **Vault Your Credentials:** Navigate to the **Settings** tab in the Nexus Interface.
2. **Inject Strategic Data:** Enter your Zerodha ID, Password, TOTP Secret, API Key, and API Secret.
3. **Ignite Sync:** Click **"Ignite Nexus Sync"**. The Nexus handles the 2FA and session autonomously.

### Option B: Manual Handshake (Fallback)
1. **Login URL:** Open `https://kite.zerodha.com/connect/login?v=3&api_key=YOUR_API_KEY`.
2. **Extract Token:** Copy the `request_token=XXXXX` string from the URL bar of the redirected page.
   - > [!IMPORTANT]
   - > **Don't Worry:** The browser WILL show a "Site can't be reached" error. This is **NORMAL**.
